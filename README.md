# 🍱 Smaood — College Smart Canteen

**Smaood** is a smart college canteen web application that lets students browse live campus menus, pre-order snacks and meals for scheduled pickup slots without waiting in queues, and track live kitchen order status alongside an admin dashboard for menu, stock, and order management.

🔗 **Live Demo:** [smaood-netlify-ready.vercel.app](https://smaood-netlify-ready.vercel.app/)

---

## ✨ Features

### 👨‍🎓 Student Portal
* **Live Campus Menu & Chef's Board:** Browse daily highlights (samosa, dosa, coffee, and more), search items, and sort by recommended, price, or fastest preparation time.
* **Smart Canteen Tray & Scheduled Pickup:** Add items to your tray and choose convenient campus pickup slots (ASAP ~10 mins, Morning Break, Lunch Break, Evening Snacks, or Hostel Dinner).
* **Live Order & Token Tracking:** Track order status in real time from your phone with zero counter waiting.

### 🧑‍🍳 Admin & Smart Kitchen Control
* **Live Order Queue Management:** Monitor new/queued orders, dishes preparing in the kitchen, and orders ready for pickup, updating student order statuses in one click.
* **Menu, Price & Stock Manager:** Add new dishes to Today's Menu, edit prices and stock quantities, or remove unavailable items.
* **Sales Overview:** Track total canteen sales in ₹ alongside active order counts.
